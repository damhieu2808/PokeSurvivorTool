# PokeSurvivor Bot

Bot tự chơi cho [pokesurvivor.com](https://pokesurvivor.com). Miễn phí.

Tác giả: **[damhieu2808](https://github.com/damhieu2808)**

## Cài đặt (Chrome trên máy tính)

1. [Tải ZIP](https://github.com/damhieu2808/PokeSurvivorTool/archive/refs/heads/main.zip) và giải nén.
2. Mở `chrome://extensions`, bật **Developer mode**.
3. Bấm **Load unpacked**, chọn thư mục vừa giải nén.
4. Mở [pokesurvivor.com](https://pokesurvivor.com), nhập số ván rồi bấm **▶ Chạy**.

## Sử dụng

- **▶ Chạy / ⏸ Tạm dừng / ■ Dừng**: điều khiển bot.
- **⚔ Moveset**: chọn 4 move ưu tiên cho từng pokémon.
- Có bản mới, bảng sẽ báo **⬆ Có bản mới**: tải lại ZIP và bấm **↻ Reload** ở `chrome://extensions`.
