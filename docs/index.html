Cài PokeSurvivor Bot

Tác giả damhieu2808 · bot tự chơi cho pokesurvivor.com

Cách 1: Tự chạy mỗi lần vào game khuyên dùng

Cài 1 lần, sau đó chỉ cần mở pokesurvivor.com.

  1. Cài app miễn phí Userscripts từ App Store.
  2. Vào Cài đặt → Safari → Tiện ích mở rộng → Userscripts: bật lên, mục Quyền chọn Cho phép (hoặc cho phép trên pokesurvivor.com).
  3. Mở trang này bằng Safari và bấm nút dưới, rồi bấm biểu tượng Userscripts (ô chữ </> hoặc ᴀA trên thanh địa chỉ) → Install.
Cài bot (userscript)

Xong: mở pokesurvivor.com, bảng PokeSurvivor Bot hiện ở góc phải trên.

Cách 2: Dấu trang (không cần cài app)

  1. Bấm nút để copy code:
  1. Trên trang bất kỳ: Chia sẻ → Thêm dấu trang → Lưu.
  2. Dấu trang → Sửa → chọn dấu trang vừa tạo: tên PokeSurvivor Bot, ô địa chỉ xoá hết rồi dán.
  3. Mỗi lần chơi: mở pokesurvivor.com → Dấu trang → PokeSurvivor Bot.

Cách 1: Tự chạy mỗi lần vào game khuyên dùng

Dùng trình duyệt Firefox, cài 1 lần, sau đó chỉ cần mở pokesurvivor.com.

  1. Cài Firefox từ CH Play.
  2. Trong Firefox: ⋮ → Tiện ích mở rộng, tìm Tampermonkey → + → Thêm.
  3. Mở trang này bằng Firefox và bấm nút dưới → Tampermonkey hiện trang cài → Install / Cài đặt.
Cài bot (userscript)

Xong: mở pokesurvivor.com trong Firefox, bảng PokeSurvivor Bot hiện ở góc phải trên.

Cách 2: Dấu trang trên Chrome (không cần cài gì)

  1. Bấm nút để copy code:
  1. Trên trang bất kỳ: ⋮ → ☆ để tạo dấu trang.
  2. ⋮ → Dấu trang, giữ dấu trang vừa tạo → Chỉnh sửa: tên PokeSurvivor Bot, ô URL xoá hết rồi dán.
  3. Mỗi lần chơi: mở pokesurvivor.com, gõ PokeSurvivor Bot lên thanh địa chỉ rồi chọn dòng dấu trang hiện ra. (Bấm từ danh sách dấu trang sẽ không chạy.)

Chrome extension đầy đủ nhất

  1. Tải ZIP và giải nén.
  2. Mở chrome://extensions, bật Developer mode.
  3. Load unpacked → chọn thư mục vừa giải nén (có file manifest.json).

Hoặc: kéo nút này lên thanh dấu trang

Không cần cài. Mở pokesurvivor.com rồi bấm dấu trang đó.
