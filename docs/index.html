Khuyên dùng Firefox. Edge / Kiwi + Tampermonkey trên Android từng không chạy được với bản cũ; với cách mới thì chưa thử lại.

  1. Cài Firefox (CH Play).
  2. Trong Firefox, cài tiện ích Violentmonkey hoặc Tampermonkey (menu ⋮ → Tiện ích).
  3. Bấm Copy, dán vào thanh địa chỉ của trình duyệt đó rồi mở:
    https://raw.githubusercontent.com/damhieu2808/PokeSurvivorTool/v2.4.1/psbot.user.js
  4. Trình quản lý tự mở trang cài script → bấm Install (Cài đặt). Đã cài bản cũ thì cài đè lên.
  5. Vào game: panel PokeSurvivor Bot hiện ở góc trên bên trái. Trình quản lý tự kiểm tra bản mới định kỳ; muốn cập nhật ngay thì bấm Check for updates trong trình quản lý.

Download the bot for PC (ZIP)

Install (Chrome on PC)

  1. Unzip the downloaded file.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  4. Open pokesurvivor.com or pokesurvivor.doofcraft.com, enter the number of runs and press ▶ Chạy (Run).

The bot's panel starts in Vietnamese: press VI | EN under its title to switch it to English. ▶ Run / ■ Stop, Runs = number of runs (0 = endless), ⚔ Moveset = pick the 4 moves the bot prefers (+2 backups). Keys: F8 toggles the bot, F9 shows what it sees.

Install (Android phone)

ℹ️ The whole bot is inside the userscript file. The userscript manager runs that code in the page itself, so pokesurvivor.com blocking scripts added to the page (CSP) no longer matters. Firefox is recommended. Edge / Kiwi + Tampermonkey on Android did not work with the old version; the new way is not tested there yet.

  1. Install Firefox (Play Store).
  2. In Firefox, install the Violentmonkey or Tampermonkey add-on (menu ⋮ → Add-ons).
  3. Tap Copy, paste into that browser's address bar and open it:
    https://raw.githubusercontent.com/damhieu2808/PokeSurvivorTool/v2.4.1/psbot.user.js
  4. The manager opens its install page → tap Install. If an older version is installed, install over it.
  5. Open the game: the PokeSurvivor Bot panel appears in the top-left corner. The manager checks for new versions on its own; to update right away, tap Check for updates in the manager.

Install (iPhone / iPad)

There are 3 ways, pick one:

Way 1: the GEAR app. Install Gear Browser (App Store). Video guide on TikTok @phuongnguyenconhat.

Way 2: the Orion browser. Install Orion Browser (App Store), add the Tampermonkey or Violentmonkey extension in Orion, then tap Copy in the Android section above, paste into the address bar, open it and tap Install.

Way 3: Userscripts in Safari.

  1. Install the Userscripts app (App Store, free).
  2. Open the iPhone / iPad Settings → scroll down to Safari → Extensions → turn on Userscripts and choose Allow on all websites.
  3. Open Safari, tap the Userscripts extension icon → + (New remote script) → tap Copy in the Android section above, paste the link and save.

Open the game: the panel appears in the top-left corner. If something goes wrong, use the contact below.
